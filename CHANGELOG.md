# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) where releases are tagged.

## [Unreleased]

### Fixed

- False clarifications: 45 of the 306 evaluation questions ended in a clarification before the model was asked, now none. Round words no longer match the gmina Turek, „mieli” no longer Mielec; a closer or longer place name beats a look-alike (Szczecin/Szczecinek, Bielsko-Biała/Biała), a person named in full beats places like the given name or surname (Przemysław Czarnek: Przemyśl, Czarne); namesakes without a candidacy in the question's year are dropped; „w mieście X” picks the town gmina. Marek Borowski's candidacies 1991–2023 are one person (override). Declined town names are recognised: „Białegostoku”, „Białymstoku”, „Krasnymstawie”, „Jeleniej Górze”, „Białej Podlaskiej”; a surname matching any word of a place name („Dąbrowie Górniczej”, „Białej Podlaskiej”) no longer adds look-alike persons.

### Added

- Multi-part questions: when one question asks two or three separate things, the model may return one SELECT per part (`{"parts": [{"title", "sql"}]}`); each part passes the SQL guard (one unsafe part rejects the answer), runs read-only, and the combined rows carry their part title in `part`. The SQL panel shows the parts as `-- part:` blocks, and the UI draws one table, chart and map per part.
- Clarifications with ready queries: an ambiguous question gets at most four options, each with a short description and a validated query written in one model call; the UI shows the description under the button, and a picked option runs its cached query without another model call.
- Thumbs-down triage: `scripts/triage_feedback.py` groups the thumbs-down questions by likely problem with the LLM (`feedback_groups.md`) and proposes a corrected query per question through the usual SQL prompt and guard; proposals with rows wait in `example_proposals.jsonl` for `add_sql_example.py --review`.
- Evaluation of LLM-written SQL: `tests/eval/questions.jsonl` (306 questions across all election families, each with a reference query or an expected clarification) and `scripts/run_eval.py`, which grades the model's rows against the reference rows and reports accuracy, clarifications, repairs, tokens, cost and time per family. CI checks every reference query against the built mart (`--check`); the nightly `Eval` workflow restores the published mart and runs the evaluation with the real model when the `OPENAI_API_KEY` secret is set. Reports record the model and a hash of the SQL rules (prompt version); `--baseline` compares with the last successful nightly report and fails on more than `EVAL_MAX_REGRESSIONS` (default 5) questions that stopped passing, listing them.
- Local recall referendums 2015–2026 (`mart.local_referenda`, 186 referendums, 231 questions): `scripts/fetch_local_referenda.py` decodes PKW's term sites on wybory.gov.pl (protobuf, no schema) into `data/pkw_html/local_referenda.csv`; the derived build checks the votes and that the commission's validity (3/5 of the voters of the organ's election) and outcome statements follow from them. Questions about recalls (odwołanie) and local referendums get the table in the prompt.
- Gmina council elections 1994 (`rada`, 2468 councils, 51,926 seats): KBW's candidate file and gmina totals (`samo1994kand`, `samo1994gm`), with the pre-1999 gmina codes and old voivodeships, single-member districts in gminas up to 40,000 inhabitants and lists in larger cities; checked against the official gmina totals and the seat allocation (modified Sainte-Laguë, `allocate_seats` method `sainte_lague_modified_whole`). Candidates are linked to persons through the 1999 powiat of their gmina. KBW publishes no 1990 local election files.
- More GUS statistics (`v_gus_units`, 2002–2024): age structure (`age_preworking_pct`, `age_working_pct`, `age_postworking_pct`), gmina budget income per resident (`gmina_income_per_capita`) and census education (`higher_education_pct`: NSP 2021 by gmina, NSP 2011 by powiat; NSP 2002 is not in BDL by unit); `fetch_gus_bdl.py --indicators` fetches only new indicators; GUS keywords for education, seniors and gmina wealth.
- Senate by-elections 2003–2025 (`mart.senat_byelections`, 24 districts): `scripts/scrape_senat_byelections.py` reads PKW's result announcements (page text, RTF, PDF) into `data/pkw_html/senat_byelections.csv`; the derived build loads it and checks that candidate votes sum to the valid votes and the winner has the most votes. By-election candidates are linked to persons (`person_id`, `v_person_history` chamber `senat_uzup`) and shown on the person card.
- Precinct areas and „mój obwód”: `mart.precincts.boundary_description` keeps PKW's „Opis granic” (Sejm 2011, 2015, 2019, 2023); `GET /precincts/find?teryt_gmina=&street=` lists the precincts of the latest such year whose area names a street or village, and the „Wyniki obwodowe” panel shows them with the commission address and jumps to the precinct.

### Changed

- Thumbs-up no longer turns an answer's SQL into a few-shot example by itself: the pair is queued in the feedback log and `scripts/add_sql_example.py --review` runs it, shows the rows and adds it to the curated file only when accepted. Unreviewed `user_confirmed` examples are removed from the OpenSearch index at startup.
- Production setup: Terraform for Hetzner (`infra/hetzner`: server with in-place rescale, data volume, firewall, Storage Box, cloud-init), `deploy/docker-compose.prod.yml` with Caddy (TLS, `/api` to FastAPI), GHCR images (`images.yml`), a deploy workflow (staging after every main build, production after approval) with `deploy/update_app.sh` and `deploy/smoke_test.sh`.
- Mart deployment without downtime: CI publishes `mart.dump` (release `mart-latest`); `deploy/deploy_mart.sh` restores it into the unused mart database and switches the API (`MART_DB`); `build_mart.py --derived-only`.
- CI: lint job (ruff, mypy with a baseline, pip-audit, offline Markdown links), mart dump cache keyed by data and builders, size report; Dependabot.
- Docs: `docs/RUNBOOK.md`, `NOTICE` (data sources and licences), `docs/ROADMAP.md`; superseded design notes moved to `docs/history/`.
- Dependencies: FastAPI 0.162 (Starlette 1.10), uvicorn 0.54, pydantic 2.14, pyarrow 26 (published advisories for Starlette 0.38 and pyarrow 18).
- `build_mart.py --jobs N` builds families in parallel processes (CI uses 3); `--skip-derived` loads family-years without rebuilding persons and views.
- Entity resolution: a capitalized or named surname beats a voivodeship or powiat adjective ("Mazowieckiego", "Tadeusz Mazowiecki" are the person; "w województwie mazowieckim" the place); a matched party alias is not a place ("PiS" is not Pisz); 1975–1998 voivodeships are dropped when a current place matched and the question names no earlier year or "województwo".
- Entity resolution: a person matches only through a word that names the surname (capitalized and not a party name when no given name is given, never the given-name word), so common words such as "w gminach", "turę", "zdobyły" or "PiS" no longer suggest persons (Gmiński, Tur, Zdobylak, Piś).
- Persons: national namesakes with one given name are split by voivodeship of residence (unless occupation, place or birth year link them) and by 1990s register birth years more than 3 apart; abbreviated 1991–2009 names ("Donald TUSK") join the person with the full name when residence or birth year confirms it (≈3,080 candidacies); local candidacies whose age contradicts a national candidacy (minimum age, 1990s ages) are no longer linked; overrides for Bartoszewski (father and son), Hofman, Kośla and Hatka. 62,535 → 60,681 national persons.
- Persons: the EP 2014 candidate and local candidate from Głowaczów is no longer merged with former president Aleksander Kwaśniewski (`person_overrides.csv`).
- `v_person_history` is a materialized view with indexes on `person_id` and `full_name` (trigram): person questions take milliseconds instead of 1.4 s.
- SQL guard also rejects quoted system functions (`"pg_read_file"(...)`) and sequence functions (`nextval`, `setval`, ...).

- `Razem` and `Bezpartyjni` aliases match only the party and the Bezpartyjni Samorządowcy movement (local committees such as "ZAWSZE RAZEM" no longer count as Razem in `v_party_results`).
- Every question goes to LLM SQL over the mart first; the legacy Sejm templates run only when it returns nothing for a plain Sejm question (not a clarification answer, follow-up or mart-only election).
- The SQL prompt describes only the relations of the election kinds the question names (plus elections, persons and cross-election views); about 7–17k instead of 27k characters of schema for such questions.
- `/ask` returns numeric values as JSON numbers (`34.27`, not `"34.27"`); questions are limited to 1000 characters.

- Questions about president, referendum, sejmik, mayors, European Parliament or Senate go to LLM SQL over the mart first instead of being matched to Sejm templates.
- Candidate `full_name` is always "Given names SURNAME" (registers that publish "SURNAME Given names" are reordered).

- Dynamic SQL (`api/services/dynamic_sql.py`) now targets only `mart`: queries are validated with sqlglot and run as the read-only `plujka_mart_reader` role (`MART_DATABASE_URL`) with a statement timeout and row cap, with one repair attempt. It no longer queries `kbw_facts` or other public tables.
